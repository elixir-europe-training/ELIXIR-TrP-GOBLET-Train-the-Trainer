## ELIXIR-GOBLET Train-the-Trainer - Lesson Plan

A day-by-day lesson plan for running the full 4-half-day TtT course, following the same lesson-plan format taught in [Session 2](session_2.md#part-vii-developing-content-and-lesson-plan): Time, Activity, Description, Materials, Learning Outcomes, and Teaching Goal.

{% capture tip_1 %}
This lesson plan is deliberately coarse - one row per major block (Welcome, Warm-up, Session, etc.), not a minute-by-minute breakdown of every Challenge within each session. The timing currently attached to individual Challenges inside each session file is being revisited separately and isn't yet reliable enough to build a fine-grained version from.
{% endcapture %}
{% include admonition.html type="tip" title="A note on granularity" content=tip_1 %}

{% capture tip_2 %}
Each day below is labeled `[DD Month YYYY]` as a placeholder - replace it with the actual dates of the specific course run before using this lesson plan.
{% endcapture %}
{% include admonition.html type="tip" title="A note on dates" content=tip_2 %}

{% capture tip_3 %}
Each of Days 1-3 runs as one continuous 13:30-17:00 flow, with a coffee break roughly every 45 minutes: Welcome/Warm-up flows directly into the start of that day's session (together forming the first ~45-min block), followed by three more ~45-min blocks, each separated by a 10-minute coffee break. The "part X of 4" segments are an even time-split for scheduling purposes only - they don't correspond to specific Parts within each session file. It's up to the instructor to judge, on the day, where a natural pause point falls (e.g. between Parts, or after a Challenge wraps up) closest to each scheduled break time.
{% endcapture %}
{% include admonition.html type="tip" title="A note on the session segments (Days 1-3)" content=tip_3 %}

{% capture tip_4 %}
Day 4 also gets three 10-minute breaks, with the same "no fixed content boundary" caveat as above - but its structure differs slightly, since Combining All the Sessions and Wrap-up keep their original times (16:10-16:55 and 16:55-17:00). To make room for the breaks without pushing those later, Session 4's content is trimmed by 30 minutes (from 130 to 100 min) and split into three segments (10/45/45 min) rather than four, with the third break landing right before Combining All the Sessions begins.
{% endcapture %}
{% include admonition.html type="tip" title="A note on Day 4's breaks" content=tip_4 %}
